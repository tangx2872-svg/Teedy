## 实验任务

1. 实际体验 Teedy 功能。
2. 列举功能性需求与非功能性需求。
3. 选择至少三个主要功能。
4. 将功能分解为用户故事。
5. 在 GitHub 创建 Projects 项目看板，并关联 Teedy 仓库。
6. 将用户故事添加至 User Story 栏。
7. 将用户故事拆分成可执行任务，添加至 Todo 栏。
8. 设置 In Progress 和 Done 栏，记录实际执行进度。

## 建议

优先考虑文档上传、文档检索、文档管理三个功能，但必须以真实源码及实际功能为准。
