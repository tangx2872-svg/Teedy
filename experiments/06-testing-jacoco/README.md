# 实验六：软件测试与覆盖率

## 状态

⬜ 未开始

## 实验任务

1. 使用 Maven 运行全部测试。
2. 验证如何运行指定测试及跳过测试。
3. 生成 Surefire 测试报告。
4. 分析测试成功率及执行耗时。
5. 配置 JaCoCo Maven 插件。
6. 生成测试覆盖率报告。
7. 分析模块、类及方法覆盖率。
8. 选择一个覆盖率较低的类，编写有效测试。
9. 重新运行 JaCoCo，对比覆盖率变化。

## 纪律要求

必须记录真实测试结果，**不得编造覆盖率数据，不得通过无意义测试虚增覆盖率**。

## 相关目录

- `reports/`：测试报告与覆盖率对比
- `notes.md`：问题与解决
