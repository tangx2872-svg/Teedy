# 实验九：Kubernetes 部署

## 状态

⬜ 未开始

## 实验任务

1. 安装 minikube 和 kubectl。
2. 创建本地 Kubernetes 集群。
3. 使用已构建的 Teedy 镜像创建 Deployment。
4. 创建 Service。
5. 验证 Teedy 可以通过 Service 访问。
6. 将 Kubernetes 部署步骤整合进 Jenkinsfile。

## 要求

保存 Kubernetes 部署配置、运行日志及真实验证结果。
