## 实验任务

1. 阅读现有 Dockerfile。
2. 构建 Teedy Docker 镜像。
3. 使用 docker run 启动容器。
4. 设置宿主机端口为 8888。
5. 验证浏览器访问。
6. 将镜像推送至 Docker Hub。
7. 将镜像构建、上传、运行整合进 Jenkins 流水线。
8. 使用实际 Commit 验证自动化过程。
